# THE WORLD IN ONE DAY — 18 November 2026

A newspaper front page that sums up the world's news of Wednesday 18 November 2026 in one 1024×1024 image, drawn procedurally by `main.ts` (Node 22, standard library only, no network, deterministic).

Lead story: Iran strikes Bahrain and Kuwait after US jets hit a missile site on Qeshm Island. Also: Ukraine hits the Kerch Bridge for a second day, Xi and Putin meet in Shenzhen before talks with Trump, Mary Peltola wins Alaska and Democrats take 56 Senate seats, and the Ebola outbreak in DR Congo more than doubles.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
